# 孳生源：黃昏調查

給第一次做埃及斑蚊孳生源調查的人使用的免費教育遊戲。3D 第一人稱，獨立恐怖遊戲風格，用 three.js r128 製作，桌機與手機（橫向）都能玩。

玩家要學會三件事：

1. 依環境判斷哪裡可能有孳生源
2. 和民眾溝通、取得同意
3. 分辨斑蚊與家蚊幼蟲

## 執行方式

不需要建置。用瀏覽器開啟 `index.html` 即可（three.js 從 cdnjs 載入，需要網路）。

本機測試建議用簡單的 HTTP 伺服器：

```bash
python3 -m http.server 8000
# 開啟 http://localhost:8000
```

## 檔案結構

| 檔案 | 內容 |
|---|---|
| `index.html` | 引擎：介面、輸入（含手機觸控）、對話系統、檢查流程、報告與結局 |
| `levels/market.js` | 第一關「廢棄市場與民宅調查」：一樓市場、二樓住家、頂樓花園 |
| `levels/studio.js` | 第二關「藝術家的工寮」：鐵皮工寮、防火巷雜物、有狗的空屋（材質與模型都寫在同一個檔案） |
| `levels/market-hd.js` | 第一關的高解析度程序材質與精細物件（水塔、廁所、垃圾等） |
| `levels/market-tex.js` | 第一關使用的小型照片材質（base64） |
| `levels/props.js` | 容器與盆栽模型庫（水桶、花盆、底盤、植物等） |
| `levels/fieldwork.js` | 現場小遊戲：滴管採樣、玻璃瓶鑑定、倒水／投藥 |
| `levels/humans.js` | 人物模型（PS1 風格、可換裝、姿勢與表情） |

## 關卡資料格式

每一關在 `window.LEVELS` 註冊一個物件，主要欄位：

- `SITES`：調查地點
- `ITEMS`：可檢查的容器（積水、幼蟲種類、處置選項、衛教說明）
- `DLG`：對話。每個選項有 `ok`（正確）、`fb`（說明）、`tone`（答錯時的反應類型：`angry`／`silent`／`locked`／`radio`）、`re`（答錯時對方的反應）
- `BRIEF`：學長簡報
- `build(K)`：建立場景；`tick`：關卡事件；`onUnlock`：對話成功後的變化

## 隨機機制

- 第二關：10 個候選容器中隨機 6 個陽性（`levels/studio.js` 的 `CAND`、`NPOS`）。
- 第一關：容器位置固定，斑蚊陽性容器總數固定為 8 個；每次開始關卡時，從 11 個候選容器中隨機決定哪些是陽性（`levels/market.js` 的 `VAR` 定義每個候選容器的陽性與陰性版本）。
- 陽性容器上不顯示蚊群。建築內會隨機出現蚊子靠近、叮咬玩家；尚未處理的陽性容器越多，出現越頻繁；持續移動較不容易被叮。
